Codex Live: manual gateway client

Experimental, source-derived protocol. Audio uses native WebRTC directly with OpenAI; the proxy WebSocket carries JSON events, not PCM audio. Only a proxy API key is needed here, never an upstream OAuth credential.

Reference sources: OMP 6d3bc569d16cd7351073eaa767caed51021befbb and Codex d30f9cc72a25d4f3d59f50a7766b6b032e3c7329. This page does not execute an agent or tools. Human-entered context is a manual delegation test, not proof of backend agent execution.

Serve this page over HTTPS or localhost for microphone access. Prefer serving from the proxy origin. Cross-origin use requires the proxy to permit this origin, Authorization/Content-Type, POST/DELETE, and expose Location, Link, and X-Live-WebSocket-Token response headers. Keys stay in page memory only. Closing this page is not a substitute for Stop.

Connection

Codex live voices: arbor, breeze, cove, ember, juniper, maple, sol, spruce, vale. This mode does not use standard Realtime voices such as marin; an incompatible voice can return a misleading 403 “Voice session access denied.”

Idle

If autoplay is blocked, press Play above. A disconnected sideband ends the call: create a new call rather than reconnecting.

Manual context injection

Sent as session.context.append or delegation.context.append, with input_text content. Text is split at Unicode codepoint boundaries into chunks of at most 500 UTF-8 bytes.
